    Implementation Roadmap¶

    Purpose¶

    This document defines the official implementation order for the project.

    Following this order minimizes breaking changes, reduces integration risks, and ensures every completed feature is fully functional before the next feature begins.

    All contributors and AI coding agents must follow this roadmap unless explicitly instructed otherwise.

    Development Principles¶

    Features are implemented as vertical slices.

    Each feature is completed end-to-end before the next feature begins.

    A feature is not considered complete until:

    • Business rules implemented
    • Backend completed
    • Tests completed
    • Customer Mobile updated (if applicable)
    • Vendor Mobile updated (if applicable)
    • Admin Web updated (if applicable)
    • Worker updated (if applicable)
    • OpenAPI updated
    • Documentation updated

    Feature Completion Checklist¶

    Before marking a feature complete:

    • Business documentation reviewed
    • Architecture reviewed
    • Skills reviewed
    • OpenAPI completed
    • Backend completed
    • Tests passing
    • Worker completed (if applicable)
    • Customer Mobile completed
    • Vendor Mobile completed
    • Admin Web completed (if applicable)
    • Documentation updated
    • Manual verification completed

    Rules¶

    Do not begin the next phase until the current phase has been completed and verified.

    Avoid parallel implementation of dependent features.

    Complete vertical slices before horizontal expansion.

    Maintain repository consistency throughout development.
