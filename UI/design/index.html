    Halal-Queue Design System¶

    Version 2.0 · August 2026

    A unified design language for the Halal-Queue platform — a halal food and shopping marketplace. Three platform variants share the same brand DNA but are adapted for their respective contexts: Mobile (iOS), Web (merchant portal & storefront), and iPad (split-view customer app).

    Brand Foundation¶

    Logo & Identity¶

    • Brand name: Halal-Queue
    • Mark: Shopping bag icon with a gold "Q" monogram and leaf motif
    • Wordmark: Calligraphic script — "Halal" in green, "Queue" in gold
    • Logo file: src/imports/logo-6.jpeg
    • Logo usage: Always on white or very dark backgrounds. Minimum size: 28px height. Never stretch or recolor.

    Brand Essence¶

    Attribute Expression
    Trust Deep forest green — certified, natural, safe
    Prestige Warm gold — quality, care, premium
    Purity White surfaces — clean, honest, transparent
    Community Rounded forms — approachable, warm, welcoming

    Color System¶

    Brand Green — Primary¶

    Used for: primary actions, navigation, halal certification marks, headings, interactive states.

    Token Hex Usage
    --green-950 #134020 Deepest green, sidebar background
    --green-900 #1B5C2A Main brand green — buttons, headers, active states
    --green-700 #246B32 Hover state on primary
    --green-600 #2E8040 Progress bars, accent fills
    --green-500 #3A9E50 Chart fills, decorative
    --green-200 #C2DFC8 Borders on light green surfaces
    --green-100 #E8F4EA Ghost button background, chip fill, success tint
    --green-50 #F4FAF5 Focused input background, subtle tint
    --green-25 #F8FDF9 Hover surface tint

    Brand Gold — Accent¶

    Used for: secondary actions, premium badges, ratings, decorative highlights, active nav indicators.

    Token Hex Usage
    --gold-900 #7A5F1A Darkest gold, rarely used
    --gold-700 #A8862C Dark gold, text on light gold surface
    --gold-500 #C8A44A Main brand gold — accents, CTAs, badges
    --gold-400 #E2C06A Lighter gold, decorative
    --gold-300 #EDD89A Muted gold, chart fills
    --gold-100 #F9F2E1 Gold surface tint
    --gold-50 #FEFBF3 Subtle gold background

    Used for: text hierarchy, surfaces, borders, disabled states.

    Token Hex Usage
    --neutral-950 #0D120D Near-black text
    --neutral-900 #1E261E Primary text
    --neutral-800 #323C32 Secondary text

    Used for: feedback states, status indicators, alerts.

    Token Hex Name Usage

    --status-warning #F59E0B Warning Low stock, certification expiry
    --status-error #EF4444 Error Payment failed, out of stock, cancelled
    --status-info #3B82F6 Info System updates, announcements

    Typography¶

    Typefaces¶

    Display — DM Serif Display¶

    • Google Fonts: family=DM+Serif+Display:ital@0;1
    • Weights available: 400 Regular, 400 Italic
    • Use for: Hero headings, brand moments, category banners, featured product titles, section titles in editorial contexts
    • Never use for: Body copy, UI labels, captions, buttons

    Body — Outfit¶

    • Google Fonts: family=Outfit:wght@300;400;500;600;700;800
    • Weights: 300 Light · 400 Regular · 500 Medium · 600 SemiBold · 700 Bold · 800 ExtraBold
    • Use for: Everything that isn't a display heading — buttons, body, labels, inputs, navigation, data

    All spacing values are multiples of 4px.

    Token Value Usage

    --space-2 8px Tight gap between related items
    --space-3 12px Gap between list items
    --space-4 16px Standard section padding, card internal gap
    --space-5 20px Screen edge padding (mobile)
    --space-6 24px Component padding (web, iPad)
    --space-8 32px Section gap
    --space-10 40px Large section gap (web)
    --space-12 48px Hero section spacing
    --space-14 56px Section gap (web hero)
    --space-16 64px Page-level vertical rhythm

    brand 0 12px 40px rgba(27,92,42,0.18) Featured product cards, hero elements

    Grid System¶

    Mobile (390px)¶

    • Columns: 1-column fluid (full width)
    • 2-column: product cards, stats calc(50% - 4px)
    • Screen padding: 16px horizontal
    • Component gap: 10–14px

    iPad (834px)¶

    • Default: 2-column for most content
    • 3-column: product grid
    • 4-column: stat cards, small tiles
    • Sidebar: 220px fixed — content area fills remaining width
    • Master-detail split: 240px list + fluid detail pane
    • Screen padding: 20px horizontal
    • Component gap: 12–16px

    Web (1280px)¶

    • Max content width: 1280px centered
    • Page padding: 40px horizontal
    • 1-column: full-width tables, hero sections
    • 2-column: form + info, chart + stats
    • 3-column: product cards, stats overview
    • 4-column: small stat cards, color swatches
    • Sidebar: 220px fixed + fluid content area
    • Component gap: 16–24px

    Motion Tokens¶

    Token Value Usage
    --dur-instant 80ms Micro feedback (tap, press)
    --dur-fast 120ms Icon swap, color change
    --dur-base 200ms State transitions, toggle
    --dur-slow 320ms Sheet appear, panel slide
    --dur-xslow 480ms Page transition, hero reveal
    --ease-standard ease-in-out General purpose
    --ease-decel cubic-bezier(0.0, 0.0, 0.2, 1) Entering elements
    --ease-accel cubic-bezier(0.4, 0.0, 1, 1) Exiting elements
    --ease-spring cubic-bezier(0.175, 0.885, 0.32, 1.275) Playful bounce, confirmation

    Cards¶

    Product Card — Horizontal (Mobile/iPad)¶

    • Background: White
    • Border: 1px --neutral-200
    • Radius: 16–18px
    • Image: 76–80px square, radius 12–14px, green gradient placeholder
    • Content: Name (700), Shop (400 muted), Price (800 green) + quantity stepper
    • Favorite button: top-right, heart icon, red when active

    Product Card — Vertical Grid¶

    • Used in: 2-col (mobile), 3-col (iPad), 4-col (web)
    • Image area: 100–120px height with gradient background, emoji placeholder
    • Badge: top-left (color-coded), rating: top-right (green bg + gold star)
    • Price + add button at bottom

    Dashboard / Info Card (Green)¶

    • Background: linear-gradient(135deg, --green-900, --green-700)
    • Used for: cart summary, order status overview, key metrics on dark surface
    • Secondary text: rgba(255,255,255,0.65)
    • Accent elements: gold badges and labels

    Stat Card (Web)¶

    • White background
    • Label: 11px / 700 / ALL CAPS / --neutral-400
    • Value: DM Serif Display / 36px / --neutral-900
    • Delta: 13px / 600 / semantic color

    Variant Background Text Usage

    Premium --green-900 White Featured, promoted items

    Organic --green-100 --green-900 Attribute tag

    All badges: font-size: 11–12px / font-weight: 700 / border-radius: 20px / padding: 4–6px 10–14px.

    Alerts & Toasts¶

    Type Left border Background Icon bg Text color
    Success #22C55E #F0FDF4 #22C55E #15803D

    Structure: border-left: 3–4px solid {color} / border-radius: 10–12px / icon is 20–22px square with 6–8px radius.

    Progress Bar¶

    • Track: --neutral-200 / border-radius: 4px
    • Fill: linear-gradient(90deg, --green-900, --green-600) or semantic color
    • Heights: 6–8px (default), 10px (large)
    • Transition: width 0.6s ease

    Step Tracker (Order Progress)¶

    • Completed step: filled --green-900 circle with white checkmark
    • Current step: --gold-500 circle with white dot
    • Upcoming step: --neutral-200 empty circle
    • Labels: 10–11px below each step

    Avatar¶

    Size Diameter Radius Font size
    XS 24px 12px 10px
    S 32px 16px 12px
    M 40px 20px 14px
    L 48px 24px 16px
    XL 56px 28px 20px

    Colors: --green-900 (primary), --gold-500 (secondary), --neutral-700 (tertiary). Initials are 2 characters, uppercase, white, font-weight: 700.

    List Rows¶

    Structure: [icon 40–42px] [title + subtitle] [right element] [chevron]

    • Row height: minimum 56px (mobile), 60px (iPad)
    • Icon container: 40–42px square, radius 10–12px, --green-100 or --neutral-100 background
    • Title: 14px / 700 / --neutral-900
    • Subtitle: 12px / 400 / --neutral-600
    • Right element: rating, price, status badge, or control
    • Divider: 1px --neutral-100 (between rows)
    • Highlighted row: --green-50 background, left accent bar optional

    Skeleton / Loading¶

    All skeleton elements use:

    • Background: --neutral-100 (#F0F2F0)
    • Radius: same as content element
    • Animation: pulse keyframe — opacity 0.5 → 1 → 0.5, 1.5s infinite (implement with CSS or Tailwind animate-pulse)
    • Never use a spinner as the primary loading state for content — use skeleton instead

    Data Table (Web)¶

    Structure:

    • Header row: --neutral-50 bg / 11px 700 ALL CAPS --neutral-400 / border-bottom: 1px --neutral-200
    • Body rows: alternate #fff / #FAFAFA
    • Row height: minimum 52px
    • Cell padding: 12px 16px
    • Action cell: View (neutral), Edit (green), Delete (red destructive)
    • Pagination: below table, right-aligned, current page = --green-900 filled

    Navigation¶

    Mobile — Bottom Tab Bar¶

    • 5 tabs: Home, Explore, Cart, Orders, Profile
    • Active: --green-900 icon + label + gold underline pip (3px, radius 2px, 20px wide)
    • Inactive: --neutral-400 icon + label
    • Badge: #EF4444 circle, white number, 8–10px radius, border: 2px solid white
    • Background: White / box-shadow: 0 -4px 20px rgba(0,0,0,0.06) / border-radius: 20px (floating style)
    • Home indicator space: 32px safe area at bottom

    iPad — Persistent Sidebar¶

    • Width: 220px (default), collapsible to 64px (icon-only)
    • Background: #1E261E (dark mode sidebar)
    • Logo: 34×34px, 9px radius
    • Nav item: 48pt min height / padding: 10–12px / border-radius: 10–12px
    • Active item: rgba(200, 164, 74, 0.15) bg + gold left-edge accent bar (3×28px) + white bold label
    • Badge: right-aligned, red circle
    • Footer: avatar + name + role, border-top: 1px rgba(255,255,255,0.07)
    • Alternative: Light sidebar — --neutral-50 bg, --green-100 active bg, --green-900 active text

    Web — Top Navigation Bar¶

    Height: 64px

    • Logo: left-aligned, 32–36px height
    • Main nav: Home Shop Categories Deals About — active item gets --green-100 bg
    • Search: center or right, --neutral-100 bg input, 200–280px wide
    • Right actions: notifications bell (with red badge) + avatar + name dropdown

    Category sub-nav strip (below main nav):

    • Background: --green-900
    • Items: rgba(255,255,255,0.8) text, 13px / 500
    • Height: 40px, horizontal scroll on narrower breakpoints

    Sidebar (merchant portal):

    • Width: 220px
    • Background: #1E261E
    • Structure same as iPad sidebar
    • Active: --gold-500 filled pill background, white text
    • Logo in header, user profile in footer

    Breadcrumbs (Web)¶

    Home / Category / Subcategory / Current Page

    • Separator: / or › in --neutral-300
    • Links: --green-900 / 400 weight
    • Current page: --neutral-900 / 600 weight, or pill --neutral-100 bg style
    • Font size: 13–14px

    Tabs¶

    Underline tabs (Web/iPad)¶

    • Tab row has border-bottom: 2px --neutral-200
    • Active tab: border-bottom: 2.5px --gold-500 (negative margin to sit on the row line)
    • Active label: --green-900 / 700
    • Inactive: --neutral-400 / 400

    Pill tabs (All platforms)¶

    • Container: --neutral-100 bg / border-radius: 10px / padding: 3–4px
    • Active pill: --green-900 bg / white label / border-radius: 7–8px
    • Inactive: transparent / --neutral-600 label

    Dropdown¶

    • Trigger: same styling as outlined input
    • Menu: white bg / border: 1px --neutral-200 / border-radius: 12px / box-shadow: md / margin-top: 4px
    • Items: padding: 11–13px 16px / border-bottom: 1px --neutral-50 / font-size: 14px / hover: --green-50 bg
    • Chevron: trailing, rotates 180° when open

    Pagination (Web)¶

    Previous / page numbers / Next

    • Current page: --green-900 filled (or --gold-500 alternate style)
    • Other pages: white bg / border: 1px --neutral-200
    • Prev / Next: text labels or arrow glyphs
    • Item size: 32–36px square, radius 8px
    • Gap: 4px between items

    Category Chips (Mobile/iPad)¶

    Horizontal scroll row (no scrollbar visible).

    • Active: --green-900 bg / white label / 1.5px --green-900 border
    • Inactive: white bg / --neutral-700 label / 1.5px --neutral-200 border
    • Height: 38pt (mobile) / 44pt (iPad)
    • Radius: 20–24px (pill)
    • Padding: 9–12px 14–18px
    • Emoji prefix for category icons

    Modal / Dialog (Web)¶

    • Backdrop: rgba(0,0,0,0.4) full-screen
    • Container: white bg / border-radius: 16px / shadow lg / max-width 480–560px (standard), 720px (wide)

    Platform-Specific Patterns¶

    Mobile (iOS · 390pt)¶

    Structure:

    [Status bar — 44px]
[App bar — variable]
[Content — scrollable]
[Bottom tab bar — 80px + safe area]

    App bar variants:

    1. Green hero bar — location + notification icon (home screen)
    2. Search bar — back icon + search input + filter button (browse screen)
    3. White detail bar — back button + centered title + action icon (detail screen)

    Touch targets: Minimum 44×44pt for all interactive elements.

    Scroll behavior: overscroll-behavior: contain on inner scroll areas. No visible scrollbars.

    Safe areas: Respect env(safe-area-inset-*) for notch, home indicator, and Dynamic Island.

    Status bar: Transparent, content appears above. Text color white on green backgrounds, dark on white.

    Home indicator: 120px wide, 5px height, --neutral-300, centered at bottom.

    iPad (iPadOS · 834pt)¶

    Structure:

    [Status bar — 24px]
[Persistent sidebar — 220px] + [Content area — fluid]
  [Top bar — 64px]
  [Content — scrollable]

    Layout approach: Sidebar + master-detail within content area. No bottom tab bar.

    Split View (master-detail):

    • List pane: 240px fixed within content area
    • Detail pane: fills remaining width
    • List items: 56–60pt min height, selected state with --green-50 bg

    Touch targets: 44pt minimum; prefer 48–52pt for primary actions.

    Pointer support: Hover states on all interactive elements (cursor: pointer). Tooltips on icon-only buttons.

    Sidebar collapse: At narrow multitasking widths (< 400pt), sidebar collapses to icon-only (64pt) or a slide-in overlay.

    Grid: 2-column default, 3-column for product grids, 4-column for stat cards. 20px screen padding. 12–16px gap.

    Web (Desktop · 1280px)¶

    Structure:

    [Sidebar — 220px] + [Main area — fluid, max 1280px]
  [Global top bar — 56px]
  [Page header — breadcrumb + title + actions]
  [Section tabs or filters]
  [Content — data tables, grids, forms, charts]

    Breakpoints: | Breakpoint | Behavior | |------------|----------| | < 768px | Single column, sidebar becomes overlay drawer | | 768–1024px | Sidebar collapses to icons (64px), 2-col content | | 1024–1280px | Full sidebar, 2–3 col content | | ≥ 1280px | Max-width container centered, full layout |

    Hover states: All interactive elements show hover via background tint or color shift. Transition: 0.18s ease.

    Focus states: box-shadow: 0 0 0 3px rgba(27,92,42,0.3) — visible keyboard focus ring.

    Cursor: cursor: pointer on all clickable elements, cursor: not-allowed on disabled.

    Scrollbars: Hide by default (scrollbar-width: none), show on hover for data tables.

    Accessibility¶

    Requirement Standard How met
    Text contrast — body 4.5:1 AA --neutral-900 on white = 18:1 ✓
    Text contrast — large 3:1 AA --green-900 on white = 7.3:1 ✓
    Text contrast — UI 3:1 AA --gold-500 on white = 2.9:1 ⚠ — use only for decorative labels, not critical info
    Touch targets 44×44pt All mobile/iPad targets enforced at 44pt minimum
    Focus visible WCAG 2.1 2.4.7 Green ring applied to all focusable elements
    Color alone WCAG 1.4.1 Status always includes icon or text alongside color
    Motion WCAG 2.3.3 All transitions respect prefers-reduced-motion

    Note on Gold: --gold-500 (#C8A44A) on white is 2.9:1 — below AA for body text. Use gold only for decorative elements (ratings, badges, accents), never for body copy or critical information. Pair with a supporting icon or dark text when conveying meaning.

    Codebase Architecture & Implementation¶

    Halal-Queue is a monorepo consisting of 3 distinct applications, each using technology tailored for its platform. The design tokens below are implemented differently depending on the application's framework.

    1. Customer App (Mobile) & Vendor App (iPad)¶

    • Path: apps/customer-app/ and apps/vendor-app/
    • Framework: Flutter (Dart)
    • Implementation Rules:
    • Do not use CSS. Colors must be implemented in a Dart AppColors class (e.g. static const Color green900 = Color(0xFF1B5C2A);).
    • Shadows use Flutter's BoxShadow widget instead of CSS shadows.
    • Fonts are loaded using the google_fonts package in pubspec.yaml, not via CSS imports.
    • Layouts use Flutter's layout widgets (Column, Row, Expanded, SizedBox) instead of CSS Grid/Flexbox.

    2. Admin Web (Desktop/Web)¶

    • Path: apps/admin-web/
    • Framework: React (Next.js)
    • Implementation Rules:
    • Add the CSS custom properties (defined below) to :root inside the main stylesheet (globals.css or index.css).
    • Fonts can be loaded via Next.js next/font/google or via @import in CSS.
    • Follows standard React/Tailwind component structures.

    Do / Don't¶

    Do¶

    • Use --green-900 as the primary action color on all platforms
    • Pair gold with green — never use gold alone as the sole primary
    • Use DM Serif Display for headings and brand moments only
    • Maintain 44pt touch targets on mobile and iPad — never go smaller
    • Use skeleton loading states for content areas, not spinners
    • Apply the brand green gradient on hero cards and summaries
    • Use semantic colors (red/green/amber) with icons, not color alone
    • Commit to the persistent sidebar on iPad — no bottom nav tab bar on iPad

    Don't¶

    • Don't use --gold-500 for body text — contrast is below AA
    • Don't mix DM Serif Display with Outfit in the same text block
    • Don't use more than 2 brand colors as backgrounds on the same screen
    • Don't make buttons smaller than 44pt on mobile/iPad
    • Don't use a bottom nav bar on iPad — use the sidebar instead
    • Don't add generic box-shadows to every card — use sm only at rest
    • Don't use Lorem Ipsum in any mockup — use real halal food/product content
    • Don't use pure black (#000000) for text — use --neutral-900 (#1E261E)
